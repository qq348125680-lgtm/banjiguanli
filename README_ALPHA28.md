# V7.0 Alpha 28 · 查询条件隔离修复

基于 Alpha 27 完整工程，修复审核记录/操作日志在分页或筛选切换时短暂显示上一查询结果的问题。

- 审核记录缓存键包含账号、班级、角色、页码、每页条数、审核状态；切换条件立即重置列表和总数。
- 操作日志独立缓存键包含账号、班级、视图、页码、每页条数；不会误清空学生名单。
- 相同查询条件刷新仍允许保留上一次成功快照；旧数据有过期提示。
- 业务写入仍默认禁用；没有修改现有 Supabase 数据。
- 核心验证：`npm test`，`npm run verify:source`，`npm run preflight:offline`。
- 完整生产构建仍需安装 React、Vite、Supabase JS 等锁定依赖，并执行 `npm run build`；没有构建成功前不要部署覆盖旧版。
