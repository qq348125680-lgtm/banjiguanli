# V7 Alpha 22 · 授权失败时的隐私数据清除

## 本次改变

- 同班普通业务读取失败时，仍可保留最近一次已授权的数据快照，并提示可能过期。
- **授权复核本身失败**（网络异常、无权等无法确定权限）时，改为安全优先：清除学生名单、审核记录、待审核数量、日志和档案面板；拒绝继续写入。
- 授权复核失败时让旧请求序号失效，避免刷新后旧响应再次写回界面。
- 无可访问班级时的“重新读取授权”改走完整复核路径，而非直接读取且保留旧授权状态。
- 授权初始化失败时也进入禁止写入状态。
- Alpha 22 不包含线上 SQL 变更，不开放新的业务写入。

## 验收边界

Node 测试与模块路径检查可离线执行。需要在可安装依赖的环境执行 `npm ci`（若有锁文件）或 `npm install`，再运行 `npm run build` 及浏览器人工回归。当前测试不是生产构建验收。
