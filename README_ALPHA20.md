# Alpha 20 — 同班刷新快照保护与跨班清空

本次直接从 Alpha 19 工程迭代：

- 同一账号、同一班级刷新时，不再先清空所有列表；网络异常会保留上次成功加载数据，并提示**可能已过期**。
- 切换班级时立即清空学生、审核、日志和计数，且中止旧请求的界面更新；账号切换继续复用 Alpha 19 隔离逻辑。
- 新增 `snapshot-policy.mjs`、9 项回归测试，以及 `npm run preflight:offline` 本地相对导入路径检查。
- 没有触碰线上 Supabase 数据库、GitHub 仓库，也没有启用正式写入。
